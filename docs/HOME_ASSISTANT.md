# Home Assistant integration

The HACS custom integration has moved to its own repository:

[PSPStreamerHA — setup, controls and limitations](https://github.com/dreimer1986/PSPStreamerHA/blob/master/docs/HOME_ASSISTANT.md).

release cycle is independent of the integration; no new PSP build is required
solely for this repository move.
