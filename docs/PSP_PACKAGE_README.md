# PSPStreamer — PSP package

Stream films, series, music and radio from your server, or play prepared offline
downloads. Includes the receiver UI, spectrum analyzer, MilkDrop and Monkey.

Copy this folder to `ms0:/PSP/GAME/PSPStreamer/`. Update the matching EBOOT.PBP
and PSPStreamer.prx together, keeping all bundled runtime PRX/font/asset files.
Preserve your existing configuration, presets, scores and downloaded media.

Start the server, then enter its address/password in the PSP's Settings.
The app's Help explains context-specific controls. Consolizer, overclocking
and external StreamMaster hardware are optional, not application requirements.

server publicly without authentication and HTTPS.
